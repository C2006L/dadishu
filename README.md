# 打地鼠大作战 (Whack-A-Mole)

基于 Unity 开发的经典打地鼠休闲游戏，支持三种难度模式、连击倍率系统和完整的 UI 交互。

## 项目简介

这是一款 Unity 2D 打地鼠游戏，玩家需要在 60 秒内尽可能多地击打从洞中冒出的地鼠来获取高分。游戏包含普通鼠、奖励鼠（金色）和炸弹鼠三种类型，并提供简单、中等、困难三种难度选择。

## 功能特性

- **三种难度模式**
  - 简单：6 个洞口，单只地鼠，速度舒缓，无特殊鼠
  - 中等：九宫格布局，最多 2 只同时出现，金色奖励鼠 +30 分
  - 困难：九宫格布局，最多 3 只同时出现，奖励鼠与炸弹鼠（-20 分）

- **连击倍率系统**
  - 连续命中 5 次：×1.5 倍率
  - 连续命中 10 次：×2 倍率（最高）
  - 点空、整批所有地鼠均未被点击或误击炸弹鼠会中断连击；多目标批次点击任意一只后不再判为整批逃脱

- **完整的 UI 系统**
  - 精美的主菜单界面，支持三种难度卡片选择
  - 游戏内 HUD 显示得分、剩余时间、当前倍率和下一倍率进度
  - 暂停面板支持音量调节、音效/音乐开关
  - 结算面板展示最终得分和详细统计

- **音效与反馈**
  - 背景音乐和打击音效
  - 得分弹出文字动画
  - 粒子火花效果
  - 击中炸弹鼠时的屏幕震动效果

- **操作方式**
  - 鼠标点击 / 触屏点击地鼠
  - 键盘 ESC 暂停/继续

## 技术栈

- **引擎**: Unity (2D)
- **语言**: C#
- **平台**: Windows / macOS / Linux (Standalone)

## 项目结构

```

├── Assets/
│   ├── Audio/              # 音频资源（背景音乐、打击音效）

│   ├── Scenes/             # 场景文件
│   ├── Scripts/            # C# 游戏脚本
│   │   ├── GameManager.cs          # 游戏主逻辑管理
│   │   ├── Mole.cs                 # 地鼠行为控制
│   │   ├── MoleSpawner.cs          # 地鼠生成器
│   │   ├── InputManager.cs         # 输入管理
│   │   ├── AudioManager.cs         # 音频管理
│   │   ├── GardenMenuController.cs # UI 菜单控制器
│   │   ├── UIThemeController.cs    # UI 主题控制器
│   │   └── HitFeedback.cs          # 击中反馈特效
│   └── Sprites/            # 精灵图资源

```

## 运行方式

1. 使用 Unity Hub 打开项目（推荐 Unity 2019 LTS 或更高版本）
2. 在 Project 窗口中打开 `Assets/Scenes/WhackAMole.unity` 场景
3. 点击 Play 按钮即可运行
4. 或通过菜单 `Tools > Whack A Mole > Rebuild Complete Project` 构建可执行文件

## 游戏规则

| 地鼠类型 | 基础分数 | 说明 |
|---------|---------|------|
| 普通鼠   | +10     | 最常出现的目标 |
| 奖励鼠   | +30     | 金色外观，仅在中等/困难模式出现 |
| 炸弹鼠   | -20     | 仅在困难模式出现，击中会中断连击并扣分 |
